# work for Introduction to Computer Graphics.

This application simulates an electrostatic field and then visualizes it using a heatmap and probes.
The entire application is written in C# and uses Windows forms.
The application allows loading of scenarios and saving the current state of the program in .json format.
It is also possible to add and remove elements in the simulation or move them to another location using Drag & Drop.




For a more detailed description of the application, see [doc/dokumentace.pdf](https://github.com/DanMas03/elfield-vis/blob/main/doc/dokumentace.pdf).
In [doc]() foder is also available a complete assignment of the work.
